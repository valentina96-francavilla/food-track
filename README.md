# FoodTrack demo

Demo statica di un portale ordini B2B per distribuzione alimentare.

- Catalogo con ricerca, categorie e ordinamento
- Preferiti
- Carrello e quantità
- Ordine simulato e storico ordini
- Riordino dimostrativo
- Profilo aziendale
- Layout responsive

**Attenzione:** prodotti, prezzi e ordini sono fittizi. Non esiste un backend, non vengono salvati dati in modo persistente e non vengono inviati ordini reali.

## GitHub Pages
In Settings → Pages, scegli `Deploy from a branch`, branch `main`, folder `/ (root)`, quindi Save. Il sito sarà pubblicato su `https://valentina96-francavilla.github.io/food-track/` quando GitHub Pages sarà attivo.
